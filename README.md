# Jack Simon — personal site

Static site, no build step. Works with GitHub Pages.

```
index.html        Overview
timeline.html     Timeline
assets/styles.css Shared styles
assets/site.js    Shows "Coming soon" for any PDF not yet uploaded
pdfs/             All PDFs linked from the site
```

PDFs the site links to (put them in `pdfs/` with exactly these names):

- goldstein-clarke-smoothing.pdf
- kepler-laws.pdf
- cv.pdf
- drp-arnold-odes.pdf
- rna-torsions.pdf
- version-control.pdf
- trig-series-notes.pdf
- power_series.pdf

To publish: push this folder to a repository, then Settings → Pages → Deploy from branch → `main` / root.
